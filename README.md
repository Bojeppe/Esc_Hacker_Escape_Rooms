Projekt Hacker Escape Rooms - HTML och CSS. För learnia kurs 2.

Projektet jobbar vi med i 9 veckors tid. 

MÅL: Bygga en hemsida  på engleska som marknadsför företagets "utmaningar/rum".

Kärnfunktioner: Säljande startsida, information om rum (lätt att uppdatera), integration med bokningssystem via API, och möjlighet att kontakta företaget.

Ska vara en responsiv startsida, fungera på både desktop och mobil.
